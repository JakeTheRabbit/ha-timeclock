# Time Clock — QOL / ease-of-use audit (2026-11-13, after 0.11.0)

Bar: the 0.11.0 My hours rebuild — calendar, day cards in time order, hour
strips, whole-day editor with Gantt, smart defaults. Apply that everywhere:
fewer taps, prefilled with the likely answer, visual context, logical
grouping, clear state and why, cross-links. Paths relative to
`timeclock/webapp/`. Effort/impact = S/M/L.

## Batch 1 — bugs + quick high-impact wins (all S, ~1 release)

| # | Area | Problem | Fix |
|---|------|---------|-----|
| 1 | **BUG** Clock | `app/(kiosk)/clock/page.tsx:114` sends only `{jobId}`; server rejects every punch with `geo_missing`/`photo_required` when geofence enforce or photoOnPunch is on (`server/routes/clock.ts:111-129`) | Send `navigator.geolocation` coords; capture photo when required; translated refusal message |
| 2 | **BUG** Roster | `app/(app)/roster/page.tsx:102` builds week end with UTC `toISOString()` → NZ week ends a day early, 7th day's shifts missing | Use `localDay()` |
| 3 | Errors | Raw API codes in toasts (`bad_request`, `already_clocked_in`, `geofence_rejected`…) on clock, leave, roster, day editor | `error.<code>` i18n map + friendly fallback, in `errMsg` |
| 4 | Entries deep link | Review/Pay/Insights/dashboard link to bare `/manager/entries` — manager re-picks person + day | Entries reads `?employeeId=&day=` (+`&edit=1`); use that link everywhere a person/day appears |
| 5 | PIN | Successful PIN sign-in stays on /pin, extra tap | `router.push("/clock")` |
| 6 | Disputes | Dispute card has no way to the disputed day | "Open this day" → selects day on calendar + opens editor; amber dot on that day |
| 7 | Day editor | Failed save closes dialog, loses reason + drafts | Keep open, refetch behind, show error on the row |
| 8 | Day editor | Reason starts blank every time | Reason chips from what changed (Forgot clock-out / clock-in / Missed break / Left site / Wrong time), prefill most likely |
| 9 | Running shift | Open shift counts 0h (`workedMinutes` null) → today shows 0.0h while clocked in | Compute live minutes client-side for open entries |
| 10 | Pay periods | Opens with nothing selected | Default to latest finished unlocked period; prev/next steppers; status chips |
| 11 | Review | Approve greyed out with no reason | Inline reason chip (still clocked in / dispute open → jump) |
| 12 | Roles | Leads see Lock that 403s; no admin Unlock UI though endpoint exists | Hide Lock < manager; admin Unlock with reason |
| 13 | Nav | Staff bottom nav has no Leave/Roster | Add both (5 tabs fit) |
| 14 | Offline | Queued offline punch leaves screen "Clocked out" → double punches | Optimistic "Clocked in (pending sync) 08:02" |
